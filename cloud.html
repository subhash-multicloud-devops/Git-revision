AWS Cloud Training Syllabus

A comprehensive roadmap covering cloud fundamentals, core infrastructure services, security, serverless, and production architecture.

8 Weeks Estimated Duration
10+ Hands-on Labs Practical Experience
Beginner to Intermediate Target Level
SAA-C03 / CLF-C02 Exam Alignment

Course Modules

Module 1 Introduction to Cloud Computing & AWS Global Infrastructure
  • Cloud Computing models: IaaS, PaaS, SaaS, and Shared Responsibility Model
  • AWS Global Infrastructure: Regions, Availability Zones (AZs), Edge Locations, and Local Zones
  • Setting up an AWS Free Tier Account & Billing Alerts via AWS Budgets
  • Navigating the AWS Management Console, CloudShell, and AWS CLI basics
Hands-on Lab: Account setup, configuring zero-dollar spend budget alerts, and AWS CLI authentication setup.
Module 2 Identity and Access Management (IAM) & Security
  • IAM Users, User Groups, Roles, and Policies (JSON Structure)
  • Multi-Factor Authentication (MFA) and Least Privilege Principle
  • AWS KMS (Key Management Service) & AWS Secrets Manager
  • AWS Organizations, Service Control Policies (SCPs), and AWS GuardDuty
Hands-on Lab: Create fine-grained IAM policies, assume a cross-service role, and enforce MFA.
Module 3 Compute Services: EC2, Containers & Serverless
  • Amazon EC2: Instance types, pricing models (On-Demand, Spot, Reserved), and AMIs
  • Storage for EC2: Elastic Block Store (EBS) and Instance Store
  • Container basics: Amazon ECS, ECR, and AWS Fargate overview
  • Introduction to Serverless: AWS Lambda and Event-driven Architecture
Hands-on Lab: Launch a secure Linux EC2 instance running an Nginx web server using User Data scripts.
Module 4 Networking & Content Delivery (Amazon VPC)
  • Virtual Private Cloud (VPC) CIDR blocks, Public & Private Subnets
  • Internet Gateways (IGW), Route Tables, and NAT Gateways
  • Security Groups (Stateful) vs. Network Access Control Lists (NACLs - Stateless)
  • VPC Peering, Transit Gateways, and AWS Route 53 (DNS Management)
  • Content delivery acceleration with Amazon CloudFront and AWS WAF
Hands-on Lab: Build a custom 2-tier VPC from scratch with public/private subnets and a NAT Gateway.
Module 5 Storage & Database Services
  • Amazon S3: Storage tiers, Lifecycle Rules, Versioning, and Bucket Policies
  • Shared file storage: Amazon EFS vs. Amazon FSx
  • Relational Databases: Amazon RDS (Multi-AZ vs. Read Replicas) & Amazon Aurora
  • NoSQL & In-Memory: Amazon DynamoDB (Partition Keys, RCUs/WCUs) & ElastiCache
Hands-on Lab: Host a static website on Amazon S3 secured with CloudFront and SSL certificates.
Module 6 High Availability, Scaling & Monitoring
  • Elastic Load Balancing (ALB, NLB, GLB) and health checks
  • Auto Scaling Groups (ASG): Scaling policies, launch templates, and metrics
  • Monitoring & Logging: Amazon CloudWatch (Metrics, Logs, Alarms) and AWS CloudTrail
  • Decoupling architectures: Amazon SQS, SNS, and EventBridge
Hands-on Lab: Deploy an auto-scaling, fault-tolerant web fleet behind an Application Load Balancer.
Module 7 Infrastructure as Code (IaC) & Well-Architected Framework
  • Introduction to AWS CloudFormation templates (YAML/JSON)
  • Overview of AWS Cloud Development Kit (CDK) & Terraform basics
  • AWS Well-Architected Framework: The 6 Pillars of architectural excellence
  • Disaster Recovery (DR) strategies: Backup & Restore, Pilot Light, Warm Standby, Multi-Region
Capstone Project: Deploy a production-ready, highly available 3-tier architecture with CloudFormation.
